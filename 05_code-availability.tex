\section*{Data, code and reproducibility}

\paragraph{Data availability.}
The thermodynamic records used in this work are from ORCHID release v2026.10 (doi:10.5281/zenodo.23736065), released under CC BY 4.0 at \url{https://data.orchid-project.org}, together with records extracted for this work that are not yet part of a release. Each plotted or fitted value carries a record id (ORC-\ldots) and the id of the equilibrium state it observes (S-\ldots). These ids are the released ones for the records of v2026.10, and are otherwise derived with the identifier rules of ORCHID or, for the records extracted for this work, assigned in the provisional namespace \texttt{local:0000-0001-7548-8686/\allowbreak 93485c57-\allowbreak c1d0-\allowbreak 4264-\allowbreak bd60-\allowbreak 93a56a517d0a}, in which they become released ids by alias. The records extracted for this work are archived, with their sources, in the evidence bundle of the assessment, from which they can be cited. The figures and assessment evidence are described in the main text and are included with their source data in the paper repository. Each record retains its citation and source location in the assessment evidence bundle. Publications that cannot be redistributed enter the evidence only through derived values and are identified by their hashes.

\paragraph{Reproducibility.}
The CALPHAD database \texttt{step4c\_b\_hingefloor\_pick.tdb} was produced by the specific protocol \texttt{crni-paper-fit-step4c-b@1.0.4}, which instantiates \texttt{orchid-calphad-fit@2.1.2}. The protocol, run cards, evidence bundle, and assessment dashboard are archived as a Workflow Run RO-Crate (doi:10.5281/zenodo.24045965), and the protocol records the SHA-256 hashes of the TDB and all its inputs, along with the command that reproduces it. The dashboard is a single self-contained file, \texttt{dashboard/dashboard.html} in the RO-Crate, which can be opened in a web browser without a network connection. ORCHID-SAGE, which comprises the general and specific protocols, the schema, the validator, the reproduction tool and the MCP server, is released with this paper under the MIT license for code and CC BY 4.0 for protocols, schema and data, at \url{https://github.com/orchid-calphad/orchid-sage} (doi:10.5281/zenodo.24045967). The fits used PhaseForge+~\cite{sariturk2025phaseforgeplus} at a commit whose source tree is identical to that of commit 2da1d69 of its public repository (\url{https://github.com/dogusariturk/PhaseForgePlus/pull/163}), and the gradient-based branch of ESPEI at commit 9039ea2 (version 0.8.11.dev82), both of which are recorded in the run cards. The scripts and data behind every figure are available in the repository of this paper (\url{https://github.com/ArroyaveLab/orchid-sage-crni-paper}, doi:10.5281/zenodo.24045969).
